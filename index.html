How It Works

  1. WASM Fileset Resolver: Downloads Google MediaPipe's WebAssembly vision runtime.
  2. Selfie Segmentation Model: Loads the local selfie_segmenter.tflite neural network running either on GPU or CPU fallback.
  3. Multi-pass Canvas Compositing: Uses the segmentation mask to composite the sharp person foreground over a Gaussian-blurred camera frame in real-time.
  4. Network Resource Tracking: Monitors Performance Resource Timing entries to calculate exact transfer volume in MB.
